# TwinStrand Biosciences

> Seattle genomics company (founded 2015) commercializing Duplex Sequencing — an error-corrected
> NGS chemistry that reads both strands of a DNA molecule independently and compares them, cutting
> error rates from ~1-in-100 to below 1-in-10,000,000 per nucleotide so ultra-rare mutations become
> detectable. Sold as DuplexSeq assay kits paired with a cloud analysis pipeline hosted on DNAnexus.

## What TwinStrand publishes for developers

Nothing. There is no developer portal, no API reference, no quickstart, no API pricing, no API
sign-up, no SDK, no CLI, no webhooks, no changelog and no status page. The api., docs.,
developer., support., portal. and status. subdomains of twinstrandbio.com do not resolve. No
/.well-known/ document of any kind is served. The DuplexSeq analysis pipeline is customer-only
software running on the DNAnexus platform and is not reachable without a DNAnexus project.

Pagination is `?page=` + `?per_page=` (max 100), with `X-WP-Total`, `X-WP-TotalPages` and an
RFC 8288 `Link` header. `_fields=` selects sparse fields; `_embed` inlines linked resources.
Errors use the WordPress `{code, message, data.status}` envelope, not RFC 9457 — and an unknown
id or route is intercepted at the edge and answered as an HTML 404 page, not JSON.
